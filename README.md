# BusDirect-Brief

Technologies utilisées

* HTML
* Tailwind CSS
* JavaScript
* LocalStorage

Fonctionnalités

* Ajouter une réservation.
* Afficher les sièges disponibles et réservés.
* Modifier le prénom et le siège d’un passager.
* Supprimer une réservation.
* Déplacer une réservation avec Drag and Drop.
* Sauvegarder les réservations dans LocalStorage.
* Calculer automatiquement le prix total des billets.

Prix des billets

Le prix d’un billet est de 80 DH.

Le prix total est calculé selon le nombre de réservations :

Prix total = Nombre de réservations × 80 DH
